# 🗺️ Travel Map Roadmap

This is a living plan, not a promise of delivery dates. Priorities will evolve based on technical learning and feedback.

## Shipped in the current prototype

- [x] React + TypeScript + Vite foundation
- [x] Minimalist GeoJSON world map
- [x] Country selection and animated zoom
- [x] Highlight countries that have memories
- [x] City markers linked to sample trip records
- [x] Story panel, photo gallery, and image viewer
- [x] Responsive mobile bottom sheet
- [x] Static deployment workflow

## Next — Make exploration delightful

- [ ] Improve geographic context and city/place labels
- [ ] Add dedicated place-level memories under each trip
- [ ] Polish desktop and mobile navigation
- [ ] Improve keyboard accessibility and reduced-motion support
- [ ] Add meaningful component and end-to-end tests
- [ ] Optimize images and asset delivery
- [ ] Establish consistent visual branding

## Future — Personal travel journals

- [ ] Authentication and user profiles
- [ ] Create and edit trips and places
- [ ] Photo uploads and media storage
- [ ] Public/private sharing options
- [ ] Personal map per user
- [ ] Data persistence and API

## Explore — Product opportunities

- [ ] Shared or collaborative travel maps
- [ ] Travel timelines and collections
- [ ] Export and backup
- [ ] Optional premium plans, validated with actual users

## Decision principles

1. Keep the experience **map-first**.
2. Deliver a usable feature before adding architectural complexity.
3. Respect user privacy and photograph ownership.
4. Measure and validate before building monetization.
